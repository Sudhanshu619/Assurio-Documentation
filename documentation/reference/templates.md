# Assurance templates

> Copyable templates for inventory, testing and decisions

The following templates are **documentation aids**, not assertions that the Assurio interface natively exports these exact formats. Copy them into your organizational process or map their fields to the configured platform.

## 1. AI system inventory

```text
System ID:
Name and business purpose:
Business / technical owner:
Intended users and affected people:
Allowed actions:
Excluded actions / populations:
Model(s), provider(s), versions:
Agents, tools and permission boundaries:
Data sources and classification:
Operating environment and baseline ID:
Applicable policies and review triggers:
```

## 2. Assurance requirement

```text
Requirement ID and revision:
Linked risk / control / policy:
Observable behavior and conditions:
Acceptance threshold / critical gate:
Test method and environment:
Responsible evaluator and reviewer:
Evidence link and baseline:
Result / uncertainty:
```

## 3. Evidence item

```text
Artifact ID and revision:
Source / collection time:
Evaluated baseline / domain:
Associated requirement / test run:
Integrity and provenance:
Observed result and limitations:
Reviewer, decision and date:
```

## 4. Decision record

```text
Decision ID:
Decision maker and delegated authority:
Baseline / system / use:
Outcome and date:
Allowed purpose / users / environments:
Restrictions / excluded operations:
Evidence package and findings:
Conditions and enforcement owners:
Residual risk / exceptions:
Expiry / reassessment trigger:
Rationale and review history:
```

## 5. Change impact report

```text
Change ID and source:
Old baseline -> new baseline:
Changed components and reasons:
Potentially affected risks / requirements:
Stale evidence and required reruns:
Evidence retained (with justification):
Operational restriction pending review:
Authorized reassessment decision and date:
```
