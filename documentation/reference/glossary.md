# Glossary

> A shared vocabulary for AI governance and assurance

| Term | Meaning |
| --- | --- |
| **AI system** | Complete AI-enabled application, including components, data, tools and oversight |
| **AI-BOM / ML-BOM** | Records describing relevant AI/ML components, dependencies, versions and provenance |
| **Acceptance authority** | Authorized person or organizational function accountable for a scoped operating decision |
| **Agent** | AI-enabled system component able to plan, use tools or perform actions |
| **Assurance case** | Structured argument linking claims, evidence and reasoning to a decision |
| **Baseline** | Identified configuration against which requirements and results apply |
| **Control** | Policy, technical or operational measure that limits or detects a risk |
| **Decision scope** | Users, purposes, components, conditions, limits and exclusions covered by authorization |
| **Evidence** | Reviewable artifact with provenance relevant to a requirement or finding |
| **Evidence ledger** | Historical record of artifacts, links, reviews and revisions |
| **Finding** | Observed deviation, limitation, gap or issue requiring a disposition |
| **GRC** | Governance, Risk and Compliance |
| **HIL** | Hardware-in-the-Loop evaluation environment |
| **Human oversight** | Named human review, escalation, intervention or acceptance responsibility |
| **Impact assessment** | Evaluation of affected people, systems, harms and consequences |
| **Inherent risk** | Exposure before additional treatment |
| **Material change** | Modification that may affect an assurance claim or approval condition |
| **MLOps** | Practices and infrastructure for operating machine-learning systems |
| **Provenance** | Source, origin, collection and processing history of an artifact |
| **Residual risk** | Exposure remaining after implemented mitigations |
| **SIL** | Software-in-the-Loop evaluation environment |
| **TEVV** | Test, Evaluation, Verification and Validation |
| **Traceability** | Links from requirements to evaluations, evidence, findings and decisions |
| **Version/Revision** | Identified state of a component, requirement or evidence item |
