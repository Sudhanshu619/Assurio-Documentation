# Import Customers

Sync your Shopify customers into Odoo contacts.

<a id="manual-import"></a>

## Manual Import

1. Navigate to **Shopify → Shopify Data → Customers**

![Navigating to Shopify Data Customers menu](https://docs.sdlccorp.com/assets/images/shopify-customer-1-f0d8384c58fb20f18fc3f65c6940ecbe.webp)

2. The customer list view shows all imported Shopify customers.

![Shopify Customers list view](https://docs.sdlccorp.com/assets/images/shopify-customer-2-3a033fde56d2a57d4b1e8087a3ae226f.webp)

3. Select your **Shopify Instance**
4. Set the **From Date** (leave empty to import all)
5. Click **Import Now**

<a id="what-gets-imported"></a>

## What Gets Imported

| Shopify Field | Odoo Field |
| --- | --- |
| First Name + Last Name | Contact Name |
| Email | Email |
| Phone | Phone |
| Address | Delivery Address |
| Company | Company Name |

<a id="creating-or-updating-customers"></a>

## Creating or Updating Customers

To create a new customer or update an existing one, open the customer form and fill in all required fields. Use the **Create in Shopify** or **Update in Shopify** buttons to sync the customer data.

![Shopify Customer form with Create and Update buttons](https://docs.sdlccorp.com/assets/images/shopify-customer-3-8ded06ad913baecec6ffafc7cf9f7933.webp)

<a id="customer-field-mapping"></a>

## Customer Field Mapping

You can also configure custom field mapping between Odoo and Shopify customer fields. Navigate to **Shopify → Mapping → Customer Mapping**.

![Mapping menu with Customer Mapping option](https://docs.sdlccorp.com/assets/images/shopify-mapp.customer-1-e77590f79c32fdf55edfc952bde0a5a3.webp)

![Customer Mapping list view](https://docs.sdlccorp.com/assets/images/shopify-mapp.customer-2-972cc81d47bdf752e78f3c01cf689b5a.webp)

To create a new mapping, click **New**, fill in the fields, and click **Test** to verify.

![Customer Mapping form - fill fields and click Test](https://docs.sdlccorp.com/assets/images/shopify-mapp.customer-3-f586af1bf23fdc2240d1ddfad5727081.webp)
