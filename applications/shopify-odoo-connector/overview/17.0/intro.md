# Shopify - Odoo Connector Documentation

Welcome to the official documentation for the **SDLC Corp Shopify - Odoo Connector** -
enterprise-grade real-time integration between Shopify and Odoo ERP.

<a id="what-is-the-shopify---odoo-connector"></a>

## What is the Shopify - Odoo Connector?

The SDLC Corp Shopify - Odoo Connector is a production-ready module that synchronizes
your Shopify store with Odoo ERP in real time. It handles products, orders, inventory,
customers, payouts, and more: fully automated with zero custom development required.

<a id="key-capabilities"></a>

## Key Capabilities

| Category | What's Synced |
| --- | --- |
| **Products** | Product listings, variants, prices, images |
| **Orders** | Unshipped, shipped, cancelled, refunded |
| **Inventory** | Stock levels, warehouse locations |
| **Customers** | Contact info, order history |
| **Financials** | Shopify payouts, net profit reports |
| **Webhooks** | Real-time event triggers |

<a id="supported-versions"></a>

## Supported Versions

- **Odoo**: v18, v19
- **Shopify**: All plans (Basic to Plus)

## Gift Cards

The connector also supports Shopify Gift Cards. Navigate to **Shopify → Gift Cards** to manage them.

![Gift Cards list view](https://docs.sdlccorp.com/assets/images/shopify-giftcard-1-6c0cca273e0f10a6cc232c2594eca3c4.webp)

To create a new gift card, click **New** and fill in the required fields.
