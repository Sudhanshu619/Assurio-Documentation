## Common Questions

<a id="does-the-connector-work-with-shopify-plus"></a>

### Does the connector work with Shopify Plus?

Yes. The connector supports all Shopify plans including Basic, Shopify, Advanced, and Plus.

---


<a id="how-many-shopify-stores-can-i-connect-to-one-odoo-instance"></a>

### How many Shopify stores can I connect to one Odoo instance?

There is no hard limit. Each store is configured as a separate Shopify Instance in Odoo.

---


<a id="does-it-support-multi-currency"></a>

### Does it support multi-currency?

Yes. Each Shopify instance can be configured with a Shopify-specific currency.

---


<a id="what-happens-if-a-sync-fails"></a>

### What happens if a sync fails?

The connector uses a queue system with automatic retry. Failed records appear in
**Shopify → Operations → Queue** with error details.

---


<a id="do-i-need-a-developer-to-install-it"></a>

### Do I need a developer to install it?

No. The connector is installed through the standard Odoo app installation process.
