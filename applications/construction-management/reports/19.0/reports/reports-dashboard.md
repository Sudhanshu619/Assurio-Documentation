# Dashboard & Analytics

The Construction Dashboard provides a real-time overview of your entire construction operations. Access it from **Construction > Dashboard**.

---


<a id="dashboard-kpis"></a>

## Dashboard KPIs

The dashboard header displays six KPI cards showing total counts for key entities:

| KPI Card | Description |
| --- | --- |
| **Projects** | Total number of construction projects |
| **Sub Projects** | Total sub-projects across all projects |
| **Material Requisitions** | Total material requisition records |
| **Phases (WBS)** | Total work breakdown structure phases |
| **Work Orders** | Total work orders |
| **Budgets** | Total budget records |

Use the **All Projects** and **All Sub Projects** filter dropdowns to scope the dashboard data to specific projects.

<a id="project-analytics"></a>

## Project Analytics

<a id="project-timeline"></a>

### Project Timeline

The **Project Timeline** chart shows the duration of each project on a horizontal bar chart, allowing you to visualize project schedules and identify overlapping timelines.

<a id="project-status"></a>

### Project Status

The **Project Status** donut chart shows the distribution of projects across states:

- **Draft** -- Projects in planning
- **In Progress** -- Active projects
- **Completed** -- Finished projects

![Project Timeline and Status](https://docs.sdlccorp.com/assets/images/photo2-20586832da474742c400b660589c708b.webp)

<a id="sub-project-analytics"></a>

## Sub Project Analytics

Track sub-project status across three pipeline stages:

| Stage | Description |
| --- | --- |
| **Planning** | Sub-projects in planning phase |
| **Procurement** | Materials and resources being procured |
| **Construction** | Active construction work |

Includes status bar charts and timeline visualization for each sub-project.

<a id="material-requisition-analytics"></a>

## Material Requisition Analytics

Monitor material requisition statuses with status cards and a donut chart:

| Status | Description |
| --- | --- |
| **Draft** | New requisitions |
| **Waiting Approval** | Pending manager approval |
| **In Progress** | POs being processed |
| **Ready to Deliver** | Materials at warehouse |
| **MRQ Done** | Requisition complete |
| **Material Orders** | Related purchase orders |
| **Internal Transfers** | Warehouse transfers |

The **Internal Transfers** section tracks Draft, In Progress, Done, and Forward Transfer counts.

<a id="cost-tracking"></a>

## Cost Tracking

<a id="budget-variance"></a>

### Budget Variance

Access budget variance data from **Construction > Budgets > Budgets**:

- **Total Planned** vs **Total Actual** amounts per budget
- **Variance** column showing cost overruns or savings
- Filter by project, sub-project, or status

<a id="rate-analysis"></a>

### Rate Analysis

Rate Analysis records at **Construction > Rate Analysis** provide per-unit cost breakdowns:

- Category-wise totals (Materials, Equipment, Labour, Overhead, Others)
- Grand total computation across all categories

<a id="extra-expense-tracking"></a>

### Extra Expense Tracking

Track unplanned costs from **Construction > Operations > Extra Expenses**:

- Filter by expense type (Material, Equipment, Labour, Transport, Permit/Fees, Other)
- Approval status tracking (Draft, Confirmed, Approved)
