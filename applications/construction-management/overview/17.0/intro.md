# Construction Management

A comprehensive Odoo module for managing construction projects end-to-end -- from project planning, budgeting, and procurement to execution, quality control, subcontracting, and invoicing. Built for Odoo Community Edition (v17, v18, v19).

![Dashboard](https://docs.sdlccorp.com/assets/images/photo1-e630a851928d9fe2a68faeff1f2be8e0.webp)

<a id="key-features"></a>

## Key Features

| Feature | Description |
| --- | --- |
| **Projects & Sub Projects** | Organize construction work into projects and sub-projects with full address, GPS, permits, and insurance tracking |
| **Bill of Quantities (BOQ)** | Create detailed BOQ with measurement dimensions, product lines, and automatic quantity computation |
| **Budget Management** | Track planned vs actual costs with variance analysis, progress percentage, and multi-stage approval workflow |
| **Rate Analysis** | Break down per-unit costs across materials, equipment, labour, overhead, and other categories |
| **Phases (WBS)** | Hierarchical Work Breakdown Structure with parent-child phases, cost tracking, and progress computation |
| **Work Orders** | Detailed work orders with material, equipment, labour, and overhead line items linked to phases |
| **Material Requisitions** | Multi-stage approval workflow with automatic purchase order and internal transfer creation |
| **Subcontracting** | Manage subcontractors with scope of work, material consume orders, RA billings, and completion certificates |
| **Progress Billing** | Milestone-based billing with work order line loading, tax computation, and direct invoice creation |
| **Quality Checks** | 8 inspection types with check points, pass/fail results, corrective actions, and document attachments |
| **Tasks & Timesheets** | Task management with priority, progress tracking, timesheet logging, and deadline management |
| **Advanced Dashboard** | Real-time KPIs, project timelines, status charts, material requisition analytics, and purchase order tracking |
