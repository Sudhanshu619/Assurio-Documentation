# Progress Tracking & Billing

Monitor construction progress, manage milestone-based billing, and ensure quality compliance across your projects.

---


<a id="progress-billing"></a>

## Progress Billing

Progress Billing enables milestone-based customer invoicing. Navigate to **Construction > Operations > Progress Billing**.

<a id="progress-billing-list-view"></a>

### Progress Billing List View

![Progress Billing List View](https://docs.sdlccorp.com/assets/images/photo30-84af051c7175102ca17d0f75d5c9e106.webp)
*Progress Billing list view with milestone names and total amounts*

<a id="progress-billing-workflow"></a>

### Progress Billing Workflow

| Stage | Description |
| --- | --- |
| **Draft** | Billing milestone created |
| **In Progress** | Work being invoiced |
| **Completed** | Billing finalized |

<a id="progress-billing-form-view"></a>

### Progress Billing Form View

| Field / Feature | Details |
| --- | --- |
| **Milestone Name** | Descriptive name for the billing milestone |
| **Customer Details** | Customer selection and Invoice Type (Type Wise or Single Invoice) |
| **Phase & Work Order** | Link to specific phase and work order |
| **Include Work Order Lines** | Checkboxes for Material, Equipment, Labour, and Overhead lines |
| **Load Work Order Lines** | Auto-populate lines from the selected work order |
| **Five Line Tabs** | Materials, Equipment, Labour, Overhead, Others -- each with tax support |
| **Create Invoice** | Generate a customer invoice directly from the billing record |
| **Invoices Smart Button** | View all generated invoices |

![Progress Billing Form - Header](https://docs.sdlccorp.com/assets/images/photo31-b9d5d04c92aa79d32880855a9e502d20.webp)
*Progress Billing form with milestone, customer details, and invoice type selection*

![Progress Billing - Work Order Lines](https://docs.sdlccorp.com/assets/images/photo32-95d78bb2ea5152a2ee71352dd946db9d.webp)

![Progress Billing - Totals](https://docs.sdlccorp.com/assets/images/photo33-0326f8300757c03d2f2ad12170837269.webp)

tip

Use the "Load Work Order Lines" button to automatically pull all line items from the linked work order. You can then adjust quantities and prices before creating the invoice.

## Quality Checks

Perform construction quality inspections with detailed check points. Navigate to **Construction > Quality Checks**.

<a id="quality-checks-list-view"></a>

### Quality Checks List View

![Quality Checks List View](https://docs.sdlccorp.com/assets/images/photo40-5c2b62760b8db87075b71a6ef03f6177.webp)
*Quality Checks list view with Configuration menu showing Work Types and Work Sub Types*

<a id="quality-check-workflow"></a>

### Quality Check Workflow

| Stage | Description |
| --- | --- |
| **Draft** | Check created |
| **In Progress** | Inspection underway |
| **Pass** | Quality standards met |
| **Fail** | Quality standards not met |
| **Conditional** | Passed with conditions |

<a id="inspection-types"></a>

### Inspection Types

The module supports 8 different inspection types:

| Check Type | Description |
| --- | --- |
| **Material Inspection** | Verify quality of incoming materials |
| **Workmanship** | Assess quality of construction work |
| **Safety** | Safety compliance checks |
| **Structural** | Structural integrity verification |
| **Electrical** | Electrical installation checks |
| **Plumbing** | Plumbing and sanitary checks |
| **Final Inspection** | Final quality assessment before handover |
| **Other** | Custom inspection types |

<a id="quality-check-form-view"></a>

### Quality Check Form View

| Tab | Details |
| --- | --- |
| **Check Points** | Detailed check items with Standard/Specification, Result (Pass/Fail/N/A), and Remarks |
| **Results** | Corrective action notes and recheck date |
| **Documents** | Attach inspection documents and images |

![Quality Check Form](https://docs.sdlccorp.com/assets/images/photo41-d9e170b417fd39527434b546674a63d6.webp)

## Tracking Project Progress

The Construction Management module provides multiple ways to monitor project progress:

<a id="phase-level-progress"></a>

### Phase-Level Progress

Each **Phase (WBS)** includes a progress percentage that reflects the completion status of work within that phase. The costing tab shows Material Cost, Equipment Cost, Labour Cost, and Overhead Cost against the total.

<a id="task-level-progress"></a>

### Task-Level Progress

Individual **Tasks** include:

- **Progress (%)** -- Manual progress tracking with visual progress bar
- **Priority** -- Normal, Low, High, or Urgent classification
- **Timesheet logging** -- Employee hours tracked against each task

<a id="budget-variance-tracking"></a>

### Budget Variance Tracking

**Budgets** provide real-time financial tracking:

- **Planned Amount** vs **Actual Amount** per line item
- **Variance** auto-computed (Planned - Actual)
- **Progress (%)** showing budget utilization

<a id="smart-button-navigation"></a>

### Smart Button Navigation

Both Projects and Sub Projects provide **smart buttons** with counts for quick navigation to:

- Sub Projects, Budgets, Phases, Work Orders
- Material Requisitions, Tasks, Extra Expenses
