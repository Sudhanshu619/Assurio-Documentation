# Visual Effects & Animations

Enable premium visual effects including particles, ripples, loading animations, and dialog transitions.

<a id="loading-styles"></a>

## Loading Styles

Choose from 10 loading animations displayed while pages load. Configure in Quick Settings under **View Preferences**:

![View Preferences - Loading](https://docs.sdlccorp.com/assets/images/08-quick-settings-view-prefs-2859bd3154d255030153bf99ff4403bc.webp)

| Style | Animation |
| --- | --- |
| **Spinner** | Classic rotating circle (default) |
| **Dots** | Three bouncing dots |
| **Pulse** | Pulsating circle |
| **Bar** | Horizontal progress bar |
| **Skeleton** | Content-shaped placeholder blocks |
| **Ripple** | Expanding circle rings |
| **Orbit** | Orbiting dots |
| **Wave** | Oscillating wave bars |
| **Bounce** | Bouncing ball |
| **Hourglass** | Rotating hourglass |

<a id="dialog-animations"></a>

## Dialog Animations

When modals and dialogs open, choose the entrance animation:

| Animation | Effect |
| --- | --- |
| **Fade** | Simple opacity transition (default) |
| **Slide Up** | Slides in from below |
| **Zoom** | Scales in from small to full size |
| **Flip** | 3D flip rotation |

<a id="visual-effect-toggles"></a>

## Visual Effect Toggles

Each effect can be individually enabled or disabled in your theme settings:

| Effect | Description | Default |
| --- | --- | --- |
| **Particles** | Lightweight floating particles in the background with mouse interaction | On |
| **Tilt** | 3D card tilt effect on kanban cards when hovering | On |
| **Magnetic** | Buttons gently attract toward the cursor on hover | On |
| **Scroll Reveal** | Content fades in as you scroll down the page | On |
| **Ripple** | Click ripple animation on primary, success, and danger buttons | On |

tip

Disable visual effects for better performance on older hardware, remote desktop connections, or when you prefer a simpler experience.

<a id="login-page"></a>

## Login Page

The login page features its own set of premium visual effects:

![Login Page](https://docs.sdlccorp.com/assets/images/31-login-page-d1e871848c90ac59b6f76b1676b8462e.webp)

- **Animated particles** with connections on canvas background
- **Floating orbs** with parallax effect and blur
- **3D card tilt**: the login card rotates in perspective when you move your mouse
- **Company logo** automatically displayed from your Odoo company settings
- **"Welcome Back"** greeting with sign-in form

<a id="login-page-layouts"></a>

### Login Page Layouts

Four layout options are available (configurable per user):

| Layout | Description |
| --- | --- |
| **Centered** | Login card centered on screen (default) |
| **Split Left** | Form on left, background on right |
| **Split Right** | Form on right, background on left |
| **Fullscreen** | Form fills entire screen |
