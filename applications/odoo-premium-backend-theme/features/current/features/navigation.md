# Navigation & Search

Power-user features for fast navigation: global search command palette, app drawer, bookmarks, and focus mode.

<a id="global-search-command-palette"></a>

## Global Search (Command Palette)

Press **Ctrl+K** or **/** to open the spotlight-style command palette:

![Global Search - Empty](https://docs.sdlccorp.com/assets/images/26-global-search-empty-1478e532795bf05a1380472d04fbfe31.webp)

Type to search across all Odoo menus, apps, and quick actions:

![Global Search - Results](https://docs.sdlccorp.com/assets/images/27-global-search-results-ca318b7b731681407d14a40de14ed921.webp)

<a id="what-you-can-search"></a>

### What You Can Search

| Category | Examples |
| --- | --- |
| **Menus** | "Sales Orders", "Invoicing", "Employees" |
| **Quick Actions** | "Toggle Dark Mode", "Toggle Focus Mode", "Toggle Fullscreen" |
| **Recent Pages** | Your last 5 visited pages (stored locally) |

<a id="keyboard-navigation"></a>

### Keyboard Navigation

| Key | Action |
| --- | --- |
| **Arrow Up/Down** | Move between results |
| **Enter** | Open selected result |
| **Escape** | Close the search |

Results are ranked by **frequency**: pages you visit often appear first.

<a id="app-drawer"></a>

## App Drawer

Press **Alt+A** to open the app drawer, a full-screen overlay showing all your installed Odoo applications:

![App Drawer](https://docs.sdlccorp.com/assets/images/28-app-drawer-00a6a6524f93668141a93eb789c4705e.webp)

<a id="pinning-apps"></a>

### Pinning Apps

Click the **star icon** on any app to pin it as a favorite:

![Pin App with Star](https://docs.sdlccorp.com/assets/images/29-app-pin-star-0c7c121e5189bf667107378a7c1770df.webp)

Switch to the **Pinned** tab to see only your favorite apps:

![Pinned Apps Tab](https://docs.sdlccorp.com/assets/images/30-pinned-app-bar-436bf99b0f08a53cd70fb90abf207c1a.webp)

<a id="app-drawer-features"></a>

### App Drawer Features

- **Search bar** at the top to filter apps by name
- **All Apps** tab shows every installed application
- **Pinned** tab shows only your starred favorites
- **Click** any app icon to navigate directly to it
- Pinned apps are stored per-user in the database

<a id="bookmarks"></a>

## Bookmarks

Press **Alt+B** on any page to bookmark it for quick access later.

- Bookmarks are stored **per-user in the database** (not browser-dependent)
- Access bookmarks from the sidebar bookmark panel
- Click any bookmark to navigate directly to that page
- Click the **X** button to remove a bookmark
- Duplicate bookmarks are automatically prevented

<a id="focus-mode"></a>

## Focus Mode

Press **Shift+F** to enter Focus Mode: a distraction-free view that hides the sidebar and non-essential UI elements:

![Focus Mode](https://docs.sdlccorp.com/assets/images/34-focus-mode-a607e02631d9219a058d8a16ad240737.webp)

In Focus Mode:

- The sidebar and top bar chrome are hidden
- An **"Exit Focus"** button appears in the corner
- Press **Escape** or click the exit button to return to normal view
- Focus Mode is temporary and not persisted between sessions

tip

Focus Mode is great for data entry, reading long forms, or presenting your screen without UI distractions.
