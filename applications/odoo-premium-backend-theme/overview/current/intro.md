# SDLC Premium Backend Theme

Welcome to the official documentation for the **SDLC Corp Premium Backend Theme**: an all-in-one premium theme for Odoo 19 with **80+ customization options**, dark mode, glassmorphism, animated login, and keyboard shortcuts.

![Theme Overview](https://docs.sdlccorp.com/assets/images/01-theme-dashboard-overview-713e86c3d244d627ac8b86742d947e75.webp)

<a id="key-capabilities"></a>

## Key Capabilities

| Category | What's Included |
| --- | --- |
| **Layout** | Vertical sidebar, mini sidebar, collapsible/pinnable navigation |
| **Theming** | 12 color palettes, custom colors, 3 UI styles (Flat, Glass, Neumorphism) |
| **Dark Mode** | Light, Dark, and Auto (system preference + smart ambient mode) |
| **Typography** | 13 Google Fonts, 3 font sizes |
| **Components** | 4 separator styles, 4 tab styles, 4 checkbox styles, 4 radio styles |
| **Visual Effects** | Particle system, ripple clicks, tilt effects, 10 loading animations |
| **Navigation** | Global search (Ctrl+K), app drawer, bookmarks, 12+ keyboard shortcuts |
| **Login Page** | Animated backgrounds with particles, orbs, and 3D card tilt |
| **Personalization** | Per-user settings, theme export/import, admin-controlled defaults |

<a id="supported-versions"></a>

## Supported Versions

- **Odoo**: v19 (Community & Enterprise)
