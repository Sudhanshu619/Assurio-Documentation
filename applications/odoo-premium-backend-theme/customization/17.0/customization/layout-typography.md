# Layout & Typography

Configure sidebar layout, font families, component styles, and view density settings.

<a id="layout-modes"></a>

## Layout Modes

The theme offers two sidebar layout modes, switchable from Quick Settings:

<a id="vertical-layout"></a>

### Vertical Layout

Full sidebar with app icons, labels, search, and sub-menus. The default experience.

![Vertical Layout](https://docs.sdlccorp.com/assets/images/17-layout-vertical-dc92c69913761e3e934bcfda0529fda0.webp)

<a id="mini-layout"></a>

### Mini Layout

Compact icon-only sidebar that saves horizontal space. Labels appear on hover.

![Mini Layout](https://docs.sdlccorp.com/assets/images/18-layout-mini-34774774c1302b10dbc05138f6ce4b69.webp)

<a id="sidebar-features"></a>

### Sidebar Features

**Pin/Unpin**: click the pin icon in the sidebar header to toggle between pinned (always visible) and unpinned (auto-collapse) modes:

![Sidebar Unpinned - Hover to Expand](https://docs.sdlccorp.com/assets/images/19-sidebar-unpinned-hover-b46bd9a03f236dd5bd2778b29312f478.webp)

When unpinned, the sidebar collapses to a thin icon strip and expands when you hover over it.

**Search**: type in the sidebar search box to instantly filter apps and menu items:

![Sidebar Search](https://docs.sdlccorp.com/assets/images/20-sidebar-search-8d1f1fce166d4209064d9ca02ef2598d.webp)

**Sub-menus**: click any app with children to expand its sub-menu inline:

![Sidebar Submenu Expanded](https://docs.sdlccorp.com/assets/images/21-sidebar-submenu-64cd5bb4c263ad9fce2811d3d6406f29.webp)

**Mini Stats**: the sidebar footer shows a task completion percentage (auto-refreshes every 5 minutes when the Project module is installed).

**Time-Based Greeting**: the sidebar footer displays a personalized greeting: "Good Morning", "Good Afternoon", or "Good Evening" based on the time of day.

<a id="top-bar"></a>

## Top Bar

The top bar spans the full width above the content area, providing quick access to key actions:

![Top Bar](https://docs.sdlccorp.com/assets/images/22-topbar-full-e72208de706500dcc5920770485ee52c.webp)

| Element | Description |
| --- | --- |
| **Greeting** | "Good Morning/Afternoon/Evening, [Name]" with emoji |
| **Company Switcher** | Displays current company name, click to switch |
| **Messaging** | Chat notification icon with unread count badge |
| **Dark Mode Toggle** | Moon icon to toggle dark/light mode (Alt+D) |
| **Gear Icon** | Opens Quick Settings panel (Alt+T): visible only with Settings Access |
| **Fullscreen** | Toggle fullscreen mode (Alt+F) |
| **User Avatar** | Click to open user preferences |

## Typography

<a id="font-families"></a>

### Font Families

Choose from 13 Google Fonts in the Quick Settings panel:

![Typography Settings](https://docs.sdlccorp.com/assets/images/06-quick-settings-typography-ad0fcf1c8127f68825aa4724af815d28.webp)

| Font | Style |
| --- | --- |
| **Inter** | Clean, modern sans-serif (default) |
| **Roboto** | Google's Material Design font |
| **Poppins** | Geometric, friendly |
| **Nunito** | Rounded, soft |
| **Open Sans** | Classic, highly readable |
| **Lato** | Professional, balanced |
| **Montserrat** | Bold, geometric headings |
| **Raleway** | Elegant, thin-to-bold range |
| **Source Sans** | Adobe's open-source workhorse |
| **DM Sans** | Compact, contemporary |
| **Work Sans** | Optimized for screens |
| **Plus Jakarta** | Modern Indonesian-inspired |
| **System** | Uses your OS default font |

<a id="font-sizes"></a>

### Font Sizes

Three size options control all text proportionally:

| Size | Effect |
| --- | --- |
| **Small** | Compact text: fits more data on screen |
| **Default** | Standard Odoo sizing |
| **Large** | Easier to read at a distance |

## View Preferences
