# Colors & Dark Mode

Personalize the theme with 12 built-in color palettes, custom colors, gradient backgrounds, UI styles, and full dark mode support.

<a id="accessing-theme-settings"></a>

## Accessing Theme Settings

Click the **gear icon** in the top bar or press **Alt+T** to open Quick Settings.

<a id="color-palettes"></a>

<a id="custom-colors"></a>

### Custom Colors

When you select **Custom**, three color pickers appear for full control:

![Custom Color Picker](https://docs.sdlccorp.com/assets/images/16-custom-colors-1c434e4c9a466308f39b3c016dc9379c.webp)

- **Primary**: main brand color (buttons, links, active states)
- **Secondary**: supporting color (backgrounds, borders)
- **Accent**: highlight color (badges, notifications, hover states)

Enter hex values directly or use the color picker.

<a id="dark-mode"></a>

## Dark Mode

Three dark mode options are available in the **Appearance** section of Quick Settings:

**Light Mode**: standard bright background:

![Light Mode](https://docs.sdlccorp.com/assets/images/14-dark-mode-light-043b69fc9d36f760c79d1a61fc1a5f83.webp)

**Dark Mode**: full dark theme with optimized colors:

![Dark Mode](https://docs.sdlccorp.com/assets/images/13-dark-mode-on-5c21f5cf5948362cd2fee3365bb1fef2.webp)

| Mode | Behaviour |
| --- | --- |
| **Light** | Always light background |
| **Dark** | Always dark background with adjusted colors for readability |
| **Auto** | Follows system preference + smart ambient mode (dark 8pm-6am, light 6am-8pm) |

Toggle dark mode instantly with **Alt+D** or click the moon icon in the top bar.

tip

Dark mode is a true dark theme: not just inverted colors. All surfaces, shadows, charts, and components are individually optimized for readability in dark mode.

<a id="theme-export-import--reset"></a>

## Theme Export, Import & Reset

At the bottom of the Quick Settings panel, you'll find three actions:

![Export, Import &amp; Reset](https://docs.sdlccorp.com/assets/images/35-export-import-2127514e576d3a3cf88b6653386f2778.webp)

- **Export**: saves your entire theme configuration as a downloadable JSON file
- **Import**: load a previously saved theme JSON file to apply it instantly
- **Reset**: restore all settings to the global defaults set by your administrator

tip

Use Export/Import to share consistent theme configurations across your team or organization.
