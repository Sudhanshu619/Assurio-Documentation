# Premium Backend Theme - Frequently Asked Questions


<a id="common-questions"></a>

## Common Questions

<a id="does-it-work-with-odoo-community-and-enterprise"></a>

### Does it work with Odoo Community and Enterprise?

Yes. The theme supports both Odoo 19 Community and Enterprise editions.

---


<a id="can-different-users-have-different-themes"></a>

### Can different users have different themes?

Yes. Each user with Settings Access can customize their own layout, colors, fonts, and effects independently. All preferences are stored per-user in the database.

---


<a id="what-happens-if-a-user-doesnt-have-settings-access"></a>

### What happens if a user doesn't have Settings Access?

They see the global defaults configured by the administrator in **Settings > SDLC Theme**. The Quick Settings gear icon is not visible to them.

---


<a id="how-do-i-grant-settings-access-to-users"></a>

### How do I grant Settings Access to users?

Go to **Settings > SDLC Theme > Settings Access > Theme Settings Users** and add the users who should have access to personal theme customization.

---


<a id="does-dark-mode-work-with-odoo-charts"></a>

### Does dark mode work with Odoo charts?

Yes. The theme syncs dark mode with Chart.js via a cookie, so all graphs and charts automatically adjust their colours.

---


<a id="can-i-share-my-theme-with-other-users"></a>

### Can I share my theme with other users?

Yes. Use **Export Theme** in Quick Settings to save your configuration as a JSON file. Other users can import it via **Import Theme** in their Quick Settings panel.

![Export, Import &amp; Reset](https://docs.sdlccorp.com/assets/images/35-export-import-2127514e576d3a3cf88b6653386f2778.webp)

---


<a id="will-the-theme-break-my-existing-odoo-modules"></a>

### Will the theme break my existing Odoo modules?

No. The theme uses non-destructive CSS overrides and does not modify core Odoo models. Uninstalling the theme returns Odoo to its default appearance.

---


<a id="how-do-i-reset-to-defaults"></a>

### How do I reset to defaults?

Open Quick Settings (**Alt+T**) and click **Reset** at the bottom of the panel. This restores all your personal settings to the global defaults.

---


<a id="does-it-affect-performance"></a>

### Does it affect performance?

Minimal impact. Visual effects (particles, tilt, magnetic, etc.) are individually toggleable. Disable them for better performance on slower connections or older hardware.

---


<a id="what-keyboard-shortcuts-are-available"></a>

### What keyboard shortcuts are available?

Press **?** on any page to see the full shortcut overlay. Key shortcuts include **Ctrl+K** (search), **Alt+D** (dark mode), **Alt+T** (settings), and **Shift+F** (focus mode).
