# Send WhatsApp from a Sale Order


<a id="step-1-open-the-sale-order"></a>

## Step 1: Open the Sale Order

Go to **Sales > Orders > Quotations** and open the order you want to send.

<a id="step-2-click-send-whatsapp"></a>

## Step 2: Click "Send WhatsApp"

Click the **Send WhatsApp** button in the form header:

![Send WhatsApp Button on Sale Order](https://docs.sdlccorp.com/assets/images/sale-order-wm-button-7682eb892ca00a82d1f9b4baec42283f.webp)

<a id="step-3-review-the-composer"></a>

## Step 3: Review the Composer

The composer popup opens with all fields auto-filled:

![Composer Popup](https://docs.sdlccorp.com/assets/images/onclick-sa-ca9e3093ea11a8d0d074dc48c6d61136.webp)

| Field | Description |
| --- | --- |
| **Document** | Order number (read-only) |
| **Recipient** | Customer name (changeable) |
| **WhatsApp Number** | Customer phone with country code (editable) |
| **WhatsApp Account** | Your connected business account |
| **Send Mode** | Template Message or Free Text |
| **WhatsApp Template** | Pre-approved message template |

<a id="message-tab"></a>

### Message Tab

The message body is pre-filled from your selected template with placeholders replaced (customer name, order number, company name). You can edit the text before sending.

<a id="attachments-tab"></a>

### Attachments Tab

![Attachments](https://docs.sdlccorp.com/assets/images/attachment-d546bf30d53d5b03ae8a4a9cd1b411c9.webp)

- **Attach PDF Document**: checked by default, attaches the order PDF
- **Download PDF Preview**: review the PDF before sending
- **Attach Attachments**: add extra files

<a id="preview-tab"></a>

### Preview Tab

Review exactly how the message will appear to the recipient:

![Message Preview](https://docs.sdlccorp.com/assets/images/preview-a3c675e0eb5c6c273d1d649d941b18a6.webp)

<a id="step-4-send"></a>

## Step 4: Send

Click **Send**. A success notification appears and the message is logged in the document's chatter.

<a id="template-message-vs-free-text"></a>

## Template Message vs Free Text

| Mode | When to Use | Restriction |
| --- | --- | --- |
| **Template Message** | First contact, confirmations, notifications | Uses pre-approved template. Can send anytime. |
| **Free Text** | Follow-ups, answering questions | Any content. Only within **24 hours** after customer last messaged you. |

warning

If you see "24-hour window expired", switch to **Template Message** mode. Free Text is only available within the 24-hour conversation window.
