# Send WhatsApp from an Invoice


<a id="identical-to-the-sale-order-flow"></a>

## Identical to the Sale Order flow

The composer, the templates, the delivery tracking - everything works the same way as on a Sale Order. The only difference is the context the form is opened from: an invoice gives you the invoice number, amount due, and the invoice partner's phone number pre-filled instead of a quotation.

If you've already read [Send from Sale Orders](from-sale-orders.md), the same steps apply here.

<a id="overview"></a>

## Overview

Sending WhatsApp from an invoice works the same way as sending from a Sale Order - same composer, same templates, same delivery tracking. The only difference is the context: the composer pre-fills with the invoice number, amount due, and the customer's phone from the invoice partner.

Refer to [Send from Sale Orders](from-sale-orders.md) for the full step-by-step.

The process is identical to sending from a Sale Order.

<a id="steps"></a>

## Steps

1. Go to **Invoicing > Customers > Invoices**
2. Open the invoice
3. Click the **Send WhatsApp** button in the header

![Send WhatsApp on Invoice](https://docs.sdlccorp.com/assets/images/invoice-form-button-146959a462da8748a520814424b252c5.webp)

4. The composer popup opens with invoice-specific template text
5. Review the message, attachments, and preview tabs
6. Click **Send**

The invoice PDF is automatically attached. The message is logged in the invoice's chatter.

tip

The same composer popup, attachment options, and preview functionality work exactly as described in the [Sale Orders guide](from-sale-orders.md).
