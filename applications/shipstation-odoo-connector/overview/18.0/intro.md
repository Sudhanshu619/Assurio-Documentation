# ShipStation - Odoo Connector


<a id="when-its-the-right-fit"></a>

## When it's the right fit

The SDLC ShipStation Odoo Connector is the right tool when you ship through multiple carriers (FedEx, UPS, USPS, DHL, regional couriers) and want to rate-shop, print labels, and track shipments without leaving Odoo. If you ship through a single carrier you have a direct contract with, a carrier-specific Odoo module is usually simpler.

<a id="overview"></a>

## Overview

ShipStation aggregates dozens of shipping carriers behind a single API. The SDLC ShipStation Odoo Connector brings that same multi-carrier capability into Odoo, so your warehouse team can rate-shop, print labels and track shipments without leaving the Odoo interface they already know.

Seamless bidirectional integration between your Odoo ERP and ShipStation shipping platform. Sync orders, customers, products, shipments, inventory, and more from within Odoo.

<a id="key-features"></a>

## Key Features

| Feature | Description |
| --- | --- |
| **Multi-Instance Support** | Connect multiple ShipStation accounts |
| **Bidirectional Order Sync** | Import/export orders with line items, rates, and tracking |
| **Product Sync** | Sync product catalog with SKU and pricing |
| **Customer Sync** | Import customer data with addresses |
| **Shipment Tracking** | Track shipments with carrier and tracking info |
| **Inventory Management** | Real-time stock levels with status alerts |
| **AI-Powered Dashboard** | Actionable insights and analytics |
| **Field Mapping** | Map any Odoo field to ShipStation field |
| **Automation Rules** | Auto-assign warehouse, carrier, and sales team |
| **Webhook Support** | Instant order and shipment updates |
