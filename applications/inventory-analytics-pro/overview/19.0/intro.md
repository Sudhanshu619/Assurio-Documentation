# Inventory Analytics Pro

Advanced inventory intelligence for Odoo: Health Scores, FSN/ABC/XYZ classifications, demand trends, automated alerts, vendor scorecards, and 1-click reorder with RFQ generation.

![Dashboard Overview](https://docs.sdlccorp.com/assets/images/03-dashboard-full-748b0596b131cf20bd0f545ba4aae9d3.webp)

<a id="key-features"></a>

## Key Features

| Feature | Description |
| --- | --- |
| **Health Score Dashboard** | Composite 0-100 score with A-F grading for every product |
| **FSN Classification** | Fast / Slow / Non-Moving based on turnover ratio |
| **ABC Revenue Analysis** | Products ranked by cumulative revenue contribution |
| **XYZ Value Classification** | Products ranked by stock value |
| **Inventory Aging** | Age brackets: 0-30, 31-60, 61-90, 91-180, 180+ days |
| **Demand Trends** | Trending Up, Declining, Stable, or Seasonal detection |
| **10 Report Types** | Specialized list views with color-coded decorations |
| **Reorder Suggestions** | Auto-calculated safety stock, reorder points, and urgency |
| **1-Click RFQ** | Create draft purchase orders directly from suggestions |
| **Vendor Scorecard** | Performance grading across delivery, quality, and price |
| **Automated Alerts** | Daily threshold-based notifications via mail activities |
| **Excel Export** | Multi-sheet formatted workbook with grade coloring |

<a id="how-it-works"></a>

## How It Works

The module reads data from your existing Odoo modules: **no separate data entry needed**:

| Your Odoo Activity | What Analytics Reads |
| --- | --- |
| Confirm sale orders | Sales volume, revenue, demand trends |
| Receive goods from vendors | Stock levels, aging, inbound movements |
| Ship goods to customers | Outbound movements, turnover calculation |
| Inventory adjustments | Stock corrections, adjustment tracking |
