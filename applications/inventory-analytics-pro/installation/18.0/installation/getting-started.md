# Inventory Analytics Pro - Getting Started


<a id="why-install-inventory-analytics-pro"></a>

## Why install Inventory Analytics Pro

Out of the box, Odoo's inventory app shows you stock-on-hand and incoming/outgoing pickings - but not whether your inventory is **healthy**. Inventory Analytics Pro answers questions like:

- Which products are tying up cash without selling?
- Which products are at stockout risk and should be reordered now?
- Which suppliers are reliable?
- Which categories are growing or shrinking?

All from a single dashboard that runs on top of your existing Odoo data - no separate database, no manual classification, no spreadsheets.

<a id="prerequisites"></a>

## Prerequisites

- **Odoo 19** (Community or Enterprise)
- Modules installed: **Inventory**, **Sales**, **Purchase**, **Accounting**
- Administrator access

<a id="installation"></a>

## Installation

Go to **Apps**, search for "Inventory Analytics", and click **Install**:

![Install Module](https://docs.sdlccorp.com/assets/images/01-apps-inventory-module-676f95e0a3c5311ce13c19fd818dc2d0.webp)

The module auto-installs its dependencies (`stock`, `sale_management`, `purchase`, `account`, `mail`).

<a id="after-installation"></a>

## After Installation

A new **Inventory Analytics** menu appears in the sidebar:

![Menu Structure](https://docs.sdlccorp.com/assets/images/02-menu-structure-df034421ea5f6b1c3fde6b1238f43ba4.webp)

| Menu | Purpose |
| --- | --- |
| **Dashboard** | Interactive analytics with charts and KPIs |
| **Reports > Generate Report** | Wizard to create specialized reports |
| **Reports > Reorder Suggestions** | Auto-calculated reorder recommendations |
| **Reports > Vendor Scorecard** | Vendor performance analysis |
| **Configuration > Alerts** | Threshold-based notification rules |

<a id="no-configuration-needed"></a>

## No Configuration Needed

The module immediately analyzes your existing Odoo data. If you have products, sales orders, and stock movements, the dashboard populates automatically.

tip

For best results, ensure you have at least 30 days of sales history and active stock in your warehouses.
