# eBay-Odoo Connector

Coming Soon

This module is currently in development and will be available soon. Documentation will be published upon release.

<a id="overview"></a>

## Overview

Manage eBay listings, orders and inventory from Odoo. Centralize your eBay marketplace operations with multi-account configuration and automated synchronization, with multi-region support to follow.

<a id="planned-features"></a>

## Planned Features

- Listing management
- Order sync
- Inventory sync
- Multi-account support
- Multi-region support (in a subsequent minor release)

<a id="planned-scope"></a>

## Planned scope

The first release will cover listing creation and updates, order import, inventory sync, and multi-account configuration. Multi-region support and motors-category quirks come in subsequent minor releases.
