# PrestaShop Connector - Customer Management

Navigate to **PrestaShop > Customers**.

<a id="customer-records"></a>

## Customer Records

Each customer record contains:

- Name, Email, Birthday, Social Title
- Default Group (Visitor / Guest / Customer)
- Partner Offers opt-in, Newsletter subscription
- Addresses (one-to-many with full address details)
- Push/Pull buttons for bidirectional sync

![Customer List](https://docs.sdlccorp.com/assets/images/PrestaShop-customer-2-2d428b8a7f0776b57538cd37afc0c4b4.webp)

<a id="customer-form"></a>

## Customer Form

![Customer Form](https://docs.sdlccorp.com/assets/images/PrestaShop-customer-3-f30e47d4d75faff1c42ffcbc776faeee.webp)

| Field | Description |
| --- | --- |
| **Social ID** | Title (Mr., Mrs., Ms.) |
| **First Name / Last Name** | Customer name |
| **Email** | Customer email address |
| **Password** | Account password |
| **Birthday** | Date of birth |
| **Newsletter** | Newsletter subscription toggle |
| **Partner Offers** | Third-party offers toggle |
| **Group Access** | Visitor, Guest, Customer roles |
| **Default Group** | Primary customer group |
| **PrestaShop Connection** | Customer ID mapping |

<a id="updating-a-customer"></a>

### Updating a Customer

Edit any field and click save. Use the push/pull buttons for bidirectional sync:

## Customer Addresses

Navigate to **PrestaShop > Customers > Addresses**.

![Address List](https://docs.sdlccorp.com/assets/images/PrestaShop-customer-add-2-2af931a9eff5289415a275f4e82af53c.webp)

<a id="creating-an-address"></a>

### Creating an Address

![Address Form](https://docs.sdlccorp.com/assets/images/PrestaShop-customer-add-3-5eac048deff03c87704f0c8e12173f20.webp)

| Field | Description |
| --- | --- |
| **Address Alias** | Friendly name (e.g. "My Address") |
| **First / Last Name** | Contact name for this address |
| **Company** | Company name |
| **VAT Number** | Tax identification number |
| **Address / Address 2** | Street address lines |
| **Zip / City** | Postal code and city |
| **Country / State** | Location |
| **Phone / Mobile** | Contact numbers |

![Address Populated](https://docs.sdlccorp.com/assets/images/PrestaShop-customer-add-4-fa3ca0d48ff5114927c3cadce1a57533.webp)

![Address Customer View](https://docs.sdlccorp.com/assets/images/PrestaShop-address-customer-1-184670fd44c362b26775b575e999b69f.webp)

tip

Each customer can have multiple addresses (billing, shipping, etc.). All addresses sync bidirectionally.
