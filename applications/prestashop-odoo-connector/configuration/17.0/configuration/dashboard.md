# PrestaShop Connector Dashboard

Navigate to **PrestaShop > Dashboard** to see a real-time overview of your PrestaShop integration.

<a id="header-controls"></a>

## Header Controls

The dashboard header provides filters and actions:

- **Instance Selector** - Filter all data by a specific PrestaShop instance, or view all
- **Date Range** - Last 8 / 14 / 30 days
- **Refresh Button** - Reload all dashboard data

<a id="kpi-cards-top-row"></a>

## KPI Cards (Top Row)

| Card | Description | Color |
| --- | --- | --- |
| **Total Amount** | Sum of all order totals in the period | Orange gradient |
| **Total Orders** | Count of orders in the period | Purple gradient |
| **Delivered Orders** | Orders with "Delivered" status | Green gradient |
| **Not Delivered** | Orders pending delivery | Pink gradient |
| **Total Customers** | All synced customers | Blue gradient |

<a id="product-status-cards-second-row"></a>

## Product Status Cards (Second Row)

| Card | Description | Color |
| --- | --- | --- |
| **Total Products** | All synced products | Blue-indigo |
| **In Stock** | Products with available stock | Green |
| **Out of Stock** | Products with zero stock | Red |
| **Low Stock** | Products below threshold | Amber |

<a id="charts"></a>

## Charts

- **Revenue Analytics** - Line chart showing daily revenue and order count over the selected date range
- **Order Status Mix** - Doughnut chart showing distribution of order statuses
- **Top Categories** - Doughnut chart showing product distribution by category

<a id="instance-status"></a>

## Instance Status

Shows all configured PrestaShop instances with their connection status:

- **Green dot** = Connected
- **Red dot** = Error
- **Gray dot** = Not connected

<a id="quick-actions"></a>

## Quick Actions

- Run Full Sync, View Sync Logs, Failed Records, Refresh Inventory
- Browse Products, Customers, Categories, Brands

<a id="sync-health"></a>

## Sync Health

Displays **Manual Runs**, **Cron Runs**, **Success Records**, and **Error Records** with a Recent Activity table showing the last 8 sync operations.
