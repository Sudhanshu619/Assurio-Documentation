# PrestaShop - Odoo Connector Documentation

Welcome to the official documentation for the **SDLC Corp PrestaShop Connector** - a powerful Odoo 18 module that provides bidirectional integration between your Odoo ERP system and one or more PrestaShop e-commerce stores. It enables real-time synchronization of products, customers, orders, categories, brands, carriers, and more.

<a id="key-features"></a>

## Key Features

- **Multi-Instance Support** - Connect and manage multiple PrestaShop stores simultaneously
- **Bidirectional Field Mapping** - Map any Odoo field to any PrestaShop API field with customizable sync direction
- **Real-time Dashboard** - Colorful analytics dashboard with charts, KPIs, and instance status
- **Auto Sync Cron** - Schedule automatic synchronization (hourly, daily, weekly, monthly)
- **Complete Data Sync** - Products, Customers, Orders, Categories, Brands, Carriers, Attributes, Features, Taxes
- **Inventory Tracking** - Real-time stock monitoring with in-stock, out-of-stock, and low-stock alerts
- **Sync Reports** - Detailed audit trail of every sync operation with success/error logging
- **PDF Reports** - Generate inventory and stock reports in PDF format

<a id="supported-versions"></a>

## Supported Versions

- **Odoo**: v18 (Community and Enterprise)
- **PrestaShop**: v1.7+ and v8.x
