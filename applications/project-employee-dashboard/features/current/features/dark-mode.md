# Dark Mode

The Project Analytics Dashboard includes full dark mode support, ensuring a comfortable viewing experience regardless of your Odoo theme preference.

<a id="how-it-works"></a>

## How It Works

The dashboard **automatically detects** your Odoo theme setting (light or dark) and adjusts the entire interface accordingly. There is no separate toggle within the dashboard -- it follows your Odoo-wide theme preference.

To switch between light and dark mode:

1. Go to **Settings** in Odoo.
2. Change the **Theme** preference to dark or light mode.
3. The dashboard adapts instantly on your next visit.

<a id="dark-mode-appearance"></a>

## Dark Mode Appearance

In dark mode, all chart colours, card backgrounds, text, borders, and grid lines are adjusted for optimal readability on dark backgrounds.

![Dark Mode](https://docs.sdlccorp.com/assets/images/33-dark-mode-full-987fe9a3114d62b733ecc26ce0208aa8.webp)

Key adaptations in dark mode:

- Stat card backgrounds use darker tones with lighter text
- Chart axes, labels, and gridlines use light colours for contrast
- Smart insight cards adapt their background and text colours
- Filter bar and modals follow the dark theme
- Progress bars and badges maintain visibility with adjusted palettes

<a id="charts-and-graphs"></a>

## Charts and Graphs

All Chart.js-powered visualizations (pie charts, bar charts, velocity trends, heatmap) dynamically adjust their:

- Background colours
- Border colours
- Axis label colours
- Grid line colours
- Tooltip styling

This ensures every chart remains readable in both modes without manual intervention.

info

Dark mode support extends to the Excel export as well -- the exported file uses a consistent colour scheme regardless of your current theme.
