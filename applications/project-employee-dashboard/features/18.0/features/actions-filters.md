# Filters, Quick Task & Navigation

Filter dashboard data, create tasks without leaving the page, navigate to Odoo views with a single click, and use fullscreen mode for presentations.

---


<a id="filters"></a>

## Filters

Click the **filter icon** in the dashboard header to expand the filter bar.

![Filter Expanded](https://docs.sdlccorp.com/assets/images/16-filter-expanded-7352253bd0a262b3e7b0be960f3adc14.webp)

The following filters are available:

| Filter | Description |
| --- | --- |
| **Project** | Filter by a specific project |
| **Department** | Filter by HR department |
| **Date From** | Show tasks created on or after this date |
| **Date To** | Show tasks created on or before this date |

<a id="applying-filters"></a>

### Applying Filters

Select your filter criteria and the dashboard updates instantly. A **badge** on the filter icon shows how many filters are currently active.

![Filter Applied](https://docs.sdlccorp.com/assets/images/17-filter-applied-f32fe6c7da3b510df87ff1fca48408b8.webp)

All charts, stat cards, insights, and the recent tasks table respond to the active filters immediately.

<a id="clearing-filters"></a>

### Clearing Filters

Click the **Clear All** button to reset all filters and return to the unfiltered dashboard view.

![Filter Cleared](https://docs.sdlccorp.com/assets/images/19-filter-clear-d0231f4827835489174dcdfee190e433.webp)

tip

The Excel export respects your active filters. Apply filters first, then export to get a focused report.

<a id="quick-task-create"></a>

## Quick Task Create

Create a new task without navigating away from the dashboard.

<a id="steps"></a>

### Steps

1. Press **N** on your keyboard or click the **+ Quick Task** button in the header.
2. Fill in the **task name** and select a **project** from the dropdown.

![Quick Task Filled](https://docs.sdlccorp.com/assets/images/21-quick-task-filled-e521f787159dde1e34aaec563ab1c38e.webp)

3. Click **Submit** to create the task.

![Quick Task Success](https://docs.sdlccorp.com/assets/images/22-quick-task-success-84fe71d40e632d63b81c316286e1744c.webp)

The task is created in Odoo and the dashboard refreshes automatically to reflect the new task in all relevant charts and metrics.

info

The quick task form creates tasks with default settings. For advanced options (assignees, deadlines, tags), open the task form after creation.

<a id="navigation-clicks"></a>

## Navigation Clicks

Several dashboard elements are clickable and navigate directly to the corresponding Odoo views.

<a id="projects-card"></a>

### Projects Card

Click the **Total Projects** stat card to open the Odoo project list view.

![Navigate to Projects](https://docs.sdlccorp.com/assets/images/29-nav-projects-aca929aeacf9d7555b99eaae05ce329c.webp)

<a id="overdue-tasks-card"></a>

### Overdue Tasks Card

Click the **Overdue Tasks** stat card to see a filtered task list showing only overdue tasks.

![Navigate to Overdue](https://docs.sdlccorp.com/assets/images/30-nav-overdue-91714f7bdcd26e4ea813e5d7ecc417eb.webp)

<a id="task-row"></a>

### Task Row

Click any row in the **Recent Tasks** table to open that task's form view for editing.

![Navigate to Task Form](https://docs.sdlccorp.com/assets/images/31-nav-task-form-74a9246e3da743e45a5f8998c923bf96.webp)

| Click Target | Where It Goes |
| --- | --- |
| **Total Projects card** | Project list view |
| **Total Employees card** | Employee list view |
| **Overdue Tasks card** | Filtered overdue task list |
| **Recent task row** | Task form view |

<a id="fullscreen-mode"></a>

## Fullscreen Mode

Press **F** or click the **expand icon** in the header to enter fullscreen mode.

![Fullscreen Mode](https://docs.sdlccorp.com/assets/images/23-fullscreen-mode-1ee9c523a3961ed152eb0f2e447212b3.webp)

Fullscreen mode hides the browser chrome and Odoo navigation for maximum dashboard visibility. Auto-refresh continues every 60 seconds, making it ideal for TV displays, stand-up meetings, or war rooms.

Press **F** again or **Escape** to return to normal mode.

![Normal Mode](https://docs.sdlccorp.com/assets/images/24-normal-mode-fbe54e5787e52e703fb2f2c932d6abff.webp)

## Keyboard Shortcuts

| Key | Action |
| --- | --- |
| **R** | Refresh dashboard data |
| **F** | Toggle fullscreen mode |
| **N** | Open quick task create modal |
