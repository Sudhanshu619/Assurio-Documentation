# Amazon - Odoo Connector

Complete **Amazon SP-API** integration with **AI-powered automation**. Connect your Amazon Seller Central account with Odoo ERP for end-to-end marketplace management across 25+ marketplaces.

| Feature | Count |
| --- | --- |
| **AI Features** | 10 |
| **AI Providers** | 4 |
| **Scheduled Actions** | 15 |
| **Marketplaces** | 25+ |

<a id="key-capabilities"></a>

## Key Capabilities

| Category | What's Included |
| --- | --- |
| **Order Management** | Auto-import FBM + FBA orders, sale order creation, delivery tracking, cancellation sync |
| **Product Catalog** | SKU/ASIN sync, 12 categories, variations, 9 image slots, bulk CSV/Excel import |
| **Pricing & Stock** | Bidirectional sync, FBA live stock, bulk price updates, Buy Box tracking |
| **Accounting** | Settlement reports, reimbursements, VCS tax invoices, reconciliation |
| **FBA Operations** | Inbound shipments (v2024 API), removal orders, Multi-Channel Fulfillment, inventory reports |
| **AI-Powered** | Listing generator, price optimizer, profit calculator, demand forecasting, smart alerts |
| **Automation** | 15 scheduled actions - orders, products, prices, stock, settlements |
| **Monitoring** | Sync reports, raw logs, real-time notifications, operation tracking |
