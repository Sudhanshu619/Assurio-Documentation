# Multi-Channel Fulfillment (MCF)

Use Amazon FBA warehouses to fulfill orders from **non-Amazon** sales channels - your own e-commerce site, eBay, Shopify, Walmart, etc.

<a id="features"></a>

## Features

- Fulfill any Odoo sale order from Amazon FBA stock
- Auto-populate MCF orders from Odoo sale orders
- Multiple shipping speed options
- Full tracking info (carrier, tracking number, ETA)
- Submit, check status, and cancel from Odoo

<a id="shipping-speed-options"></a>

## Shipping Speed Options

| Speed | Delivery Time | Cost |
| --- | --- | --- |
| **Standard** | 3–5 business days | Lowest |
| **Expedited** | 2 business days | Medium |
| **Priority** | 1 business day | Highest |

<a id="how-it-works"></a>

## How It Works

1. Customer places an order on your non-Amazon channel
2. Sale order is created in Odoo (manually or via other connector)
3. On the sale order, click **Fulfill via Amazon MCF**
4. Select shipping speed and confirm shipping address
5. Amazon picks, packs, and ships from FBA inventory
6. Tracking info automatically updates in Odoo

<a id="order-status-tracking"></a>

## Order Status Tracking

Full tracking info syncs back to Odoo:

- **Carrier Name** (UPS, USPS, FedEx, etc.)
- **Tracking Number**
- **Estimated Delivery (ETA)**
- **Delivery Status**

<a id="creating-an-mcf-order"></a>

## Creating an MCF Order

<a id="from-sale-order"></a>

### From Sale Order

1. Open any Odoo sale order
2. Click **Fulfill via Amazon MCF** button
3. Select shipping speed
4. Confirm shipping address
5. Submit

<a id="manual-entry"></a>

### Manual Entry

1. Go to **FBA > MCF Orders** and click **New**
2. Enter customer shipping details
3. Add SKUs and quantities (must be FBA-stocked)
4. Select shipping speed
5. Submit

<a id="cancellation"></a>

## Cancellation

MCF orders can be cancelled before Amazon ships them:

1. Open the MCF order in Odoo
2. Click **Cancel Order**
3. If Amazon hasn't shipped yet, it's cancelled free
4. If already shipped, normal return process applies

tip

MCF is ideal if you sell on multiple channels (Shopify + Amazon, eBay + Amazon, etc.) and want a single fulfillment point. You only need to manage FBA inventory instead of multiple warehouses.
