# Access Management

Coming Soon

This module is currently in development and will be available in Q4 2026. Documentation will be published upon release.

<a id="overview"></a>

## Overview

Granular role-based access control for Odoo. Define field-level permissions, maintain comprehensive audit trails, and integrate single sign-on for enhanced security across your Odoo environment.

<a id="planned-features"></a>

## Planned Features

- Field-level permissions
- Audit trails
- SSO integration

<a id="what-you-can-do-today"></a>

## What you can do today

While Access Management is in development:

- Use Odoo's built-in **Settings → Users & Companies → Groups** for role-based access. The core ACL primitives are already present in Odoo Community.
- Record-rule and field-level restrictions can be authored manually until this module ships with a UI on top of them.
- Subscribe to the SDLC Corp newsletter at [sdlccorp.com](https://sdlccorp.com) so you hear about the Q4 2026 beta first.
