# BigCommerce - Odoo Connector


<a id="when-it-fits"></a>

## When it fits

The SDLC BigCommerce Odoo Connector is the right fit when you've outgrown BigCommerce's built-in catalog/order tools and want Odoo to own the business logic - inventory across multiple warehouses, multi-channel selling, advanced accounting, or any workflow that depends on Odoo's ERP foundation.

<a id="overview"></a>

## Overview

The SDLC BigCommerce Odoo Connector keeps your BigCommerce store and Odoo ERP in step using a combination of REST API calls and BigCommerce webhooks. Sync is fully bidirectional so you can let either system be the source of truth for any record type.

Complete bidirectional integration between your Odoo ERP and BigCommerce online store. Sync products, orders, customers, categories, and inventory with real-time webhook support, AI-powered dashboard, and flexible field mapping.
