# SDLC Project Costing

A comprehensive project financial management module for Odoo that enables businesses to track, analyze, and control project costs with precision. Manage budgets for fixed-cost projects, record client payments for variable-cost engagements, track labor costs through timesheets, log extra expenses, and monitor profitability through an interactive financial dashboard -- all within your existing Odoo Project workflow.

![Project Financial Dashboard](https://docs.sdlccorp.com/assets/images/photo1-f76f14748d62f046ecc5439dc01c88ab.webp)

<a id="key-features"></a>

## Key Features

| Feature | Description |
| --- | --- |
| **Project Types** | Classify projects as **Fixed Cost** or **Variable Cost** to drive different financial workflows |
| **Budget Management** | Define and track approved budgets per project with automatic over-budget alerts |
| **Extra Costs** | Log miscellaneous project expenses (software, travel, subcontractors) with date, description, and amount |
| **Client Payments** | Record installment or milestone payments from clients for variable cost projects |
| **Timesheet Costing** | Auto-calculate labor costs based on employee hourly rates and hours logged on timesheets |
| **Financial Dashboard** | Interactive KPI cards, bar charts, cost/revenue breakdowns, and detailed budget tables |
| **Security & Access** | Dedicated **Project Finance Management** security group with granular access control |

<a id="quick-start"></a>

## Quick Start

1. **Install the module** -- Download and install `project_costing` from the Odoo Apps menu
2. **Set Project Types** -- Open each project and select **Fixed Cost** or **Variable Cost**
3. **Enter Budgets** -- For fixed-cost projects, set the approved **Project Budget**
4. **Configure Employee Costs** -- Ensure each employee has an **Hourly Cost** in their HR Settings
5. **Explore the Dashboard** -- Navigate to **Project > Dashboard** to view your financial overview
