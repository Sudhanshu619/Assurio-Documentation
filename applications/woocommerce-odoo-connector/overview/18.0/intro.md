# WooCommerce - Odoo Connector


<a id="overview"></a>

## Overview

The SDLC WooCommerce Odoo Connector is a production-grade integration between WordPress WooCommerce stores and Odoo ERP. It uses WooCommerce's official REST API to push and pull data on a schedule or in real-time via webhooks - no plugin install needed on the WooCommerce side beyond enabling REST.

<a id="who-its-for"></a>

### Who it's for

- **Online retailers** running WooCommerce who use Odoo for accounting, inventory or CRM.
- **Multi-store operators** consolidating sales from several WooCommerce stores into one Odoo backend.
- **Agencies** rolling out Odoo to WooCommerce-based clients without rebuilding the front-end.

Complete bidirectional integration between your Odoo 18 ERP and WooCommerce online store. Sync products, orders, customers, categories, coupons, and inventory with AI-powered features and real-time webhooks.

## Key Features
