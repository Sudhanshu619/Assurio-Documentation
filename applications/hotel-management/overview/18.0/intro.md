# Hotel Management System

Complete, enterprise-grade **hotel management solution for Odoo 19** - covering every aspect of hotel operations from reservations to housekeeping, restaurant to guest portal.

![Hotel Dashboard](https://docs.sdlccorp.com/assets/images/03_dashboard_all_exec_summary-ec2f9fbd134a0f24f399872fa8dda72a.webp)

<a id="key-capabilities"></a>

## Key Capabilities

| Area | What's Included |
| --- | --- |
| **Property & Rooms** | Multi-property support, floor/room configuration, amenity tracking |
| **Reservations** | Full booking lifecycle (draft → checkout), calendar views, room grid |
| **Guest Management** | Guest profiles, ID tracking, VIP status, stay history, preferences |
| **Folio & Billing** | Automated guest folios, itemized charges, tax, payment tracking, invoices |
| **Housekeeping** | Task scheduling, room status, staff assignment, lost & found |
| **Restaurant** | Table management, food ordering, kitchen order tickets (KOT) |
| **Services** | Laundry, spa, transport, and custom service management |
| **Rate Plans** | Dynamic pricing, seasonal rates, promotional offers |
| **Guest Portal** | Public booking portal, reservation self-service, payment confirmation |
| **Reports & Analytics** | Occupancy, revenue, booking source, VIP/repeat guest reports |

<a id="dashboards"></a>

## Dashboards

The system includes **5 role-specific dashboards** with KPIs, charts, and alerts:

| Dashboard | Purpose |
| --- | --- |
| **All / Executive** | Complete overview - arrivals, departures, occupancy, revenue, alerts |
| **Front Desk** | Pending actions, arrivals, today's check-ins |
| **Housekeeping** | Dirty rooms, completed tasks, staff workload |
| **Owner / Stats** | Today's income, RevPAR, ADR, booking metrics |
| **Analytics** | Charts, KPIs, occupancy trends, booking sources |

<a id="supported-versions"></a>

## Supported Versions

- **Odoo:** 19.0 Community and Enterprise
- **License:** LGPL-3
- **Module Version:** 19.0.4.0.0

<a id="dependencies"></a>

## Dependencies

- `mail` (messaging, tracking)
- `account` (folios, invoicing)
- `contacts` (guest profiles)
- `portal` (guest self-service)
