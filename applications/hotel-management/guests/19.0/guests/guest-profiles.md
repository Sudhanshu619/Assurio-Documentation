# Guest Profiles

Complete guest relationship management with identification tracking, VIP status, preferences, and stay history.

<a id="guest-form"></a>

## Guest Form

![Guest Form](https://docs.sdlccorp.com/assets/images/21_guest_form-3e1cf68c7ebf1ddf312b874c26f5de3b.webp)

<a id="main-fields"></a>

### Main Fields

| Field | Description |
| --- | --- |
| **Guest Name** | Full name (or pulled from linked contact) |
| **Contact** | Linked `res.partner` for integrated contact management |
| **Email** | Guest email for confirmations and communications |
| **Phone** | Primary contact number |
| **Nationality** | Country of nationality |
| **Date of Birth** | For age verification and birthday offers |
| **Gender** | Male / Female / Other |
| **Guest Photo** | Profile image |
| **VIP Status** | Mark as VIP for priority treatment |

<a id="identification"></a>

## Identification

<a id="id-types-supported"></a>

### ID Types Supported

- **Passport** (international travelers)
- **National ID** (residents)
- **Driving License** (common in hotels)
- **Other** (custom ID types)

<a id="id-document-capture"></a>

### ID Document Capture

![Guest ID Documents](https://docs.sdlccorp.com/assets/images/23_guest_id_documents-5d340f6a0040548c7d4cd9b70a9e0813.webp)

Upload front and back images of identification:

- ID document (front)
- ID document (back)
- Expiry date tracking
- Automatic expiry alerts

tip

Capture ID documents at check-in for compliance. Some countries require ID verification by law - the module keeps everything in one place.

<a id="guest-preferences"></a>

## Guest Preferences

Track guest preferences to personalize their stays:

![Guest Preferences](https://docs.sdlccorp.com/assets/images/22_guest_preferences-212588eff59a9f5a3dd0c2ee129643ff.webp)

Examples:

- Preferred room type or view
- Bedding preferences
- Dietary restrictions
- Allergies
- Special requests (extra pillows, non-smoking, etc.)
- Preferred check-in time

Preferences appear on future reservation forms and reports so staff can prepare in advance.

<a id="vip-guests"></a>

## VIP Guests

Mark guests as VIP for:

- Priority room assignment
- Automatic welcome gifts
- VIP-only dashboards / reports
- Front desk alerts when they arrive
- Custom rate plans

View all VIP guests in **Reporting > VIP & Repeat Guests**:

![VIP Repeat Report](https://docs.sdlccorp.com/assets/images/34_report_vip_repeat-8501b5534984f1846f075b1fb70a9fcd.webp)

<a id="stay-history"></a>

## Stay History

Each guest profile shows:

- Total stays
- Total nights
- Total revenue generated
- Last visit date
- Favorite rooms
- Previous folios and invoices
- Previous feedback ratings

This helps staff provide personalized service and identify your best customers.

<a id="creating-a-new-guest"></a>

## Creating a New Guest

Three ways to add a guest:

<a id="1-from-a-reservation"></a>

### 1. From a Reservation

When creating a reservation, click **Create and Edit** in the Guest field. Fill in guest details and save.

<a id="2-from-contacts"></a>

### 2. From Contacts

Navigate to **Contacts**, create a contact, then it can be used as a Hotel Guest.

<a id="3-directly"></a>

### 3. Directly

Navigate to **Front Desk > Guests** and click **New**. Fill in all guest information.

<a id="merge-duplicate-guests"></a>

## Merge Duplicate Guests

If duplicate guest records are created (same person booked twice with different emails), use the **Merge** feature to combine them. All reservations, folios, and history consolidate into one guest record.
