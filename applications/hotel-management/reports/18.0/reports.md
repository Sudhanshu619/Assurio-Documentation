# Hotel Management - Reports & Analytics

Comprehensive reporting across revenue, occupancy, guests, and operations.

<a id="report-types"></a>

## Report Types

The module includes pre-built reports accessible via **Reporting** menu:

| Report | Purpose |
| --- | --- |
| **Daily Revenue** | Day-by-day revenue breakdown |
| **Arrivals & Departures** | Expected check-ins/outs for date range |
| **Booking Source** | Revenue by source (direct, OTA, walk-in, corporate) |
| **VIP & Repeat Guests** | High-value guest analysis |
| **Occupancy Report** | Room occupancy over time |
| **Folio Report** | Individual folio printout |
| **Room Revenue** | Revenue per room type or room |
| **Housekeeping Report** | Task completion and staff performance |
| **KOT Report** | Restaurant kitchen order tickets |
| **Reservation Report** | Booking details printout |

<a id="key-hotel-metrics"></a>

## Key Hotel Metrics

The system calculates industry-standard KPIs automatically:

| Metric | Formula | What It Shows |
| --- | --- | --- |
| **ADR** | Room Revenue / Rooms Sold | Average nightly rate |
| **RevPAR** | Room Revenue / Rooms Available | Revenue per available room |
| **Occupancy %** | Rooms Sold / Rooms Available × 100 | Fill rate |
| **Length of Stay** | Total Nights / Reservations | Average stay duration |
| **Booking Lead Time** | Avg days between booking & arrival | Planning insight |
