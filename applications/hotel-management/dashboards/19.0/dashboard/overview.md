# Hotel Management Dashboard Overview

The Hotel Management System provides **5 role-specific dashboards** accessible from the **Dashboard** menu, each tailored to a specific user role.

<a id="all--executive-summary"></a>

## All / Executive Summary

The main dashboard with a complete overview of hotel operations.

![Executive Summary](https://docs.sdlccorp.com/assets/images/03_dashboard_all_exec_summary-ec2f9fbd134a0f24f399872fa8dda72a.webp)

<a id="top-cards"></a>

### Top Cards

| Card | What It Shows |
| --- | --- |
| **Arrivals** | Today's expected check-ins |
| **Departures** | Today's expected check-outs |
| **VIPs** | Upcoming VIP guests |
| **Available** | Rooms available for booking |
| **Occupancy** | Current occupancy percentage |
| **Today's Revenue** | Revenue generated today |

<a id="sections"></a>

### Sections

- **Front Desk** - Pending actions for staff
- **Housekeeping** - Dirty rooms, tasks status
- **Owner** - Revenue metrics, RevPAR, ADR
- **Operational Alerts** - Overdue checkouts, no-shows, dirty rooms, maintenance pending

<a id="front-desk-dashboard"></a>

## Front Desk Dashboard

Focused view for front desk staff showing pending actions and arrivals.

![Front Desk Cards](https://docs.sdlccorp.com/assets/images/04_dashboard_front_desk_cards-1bdc292910648ede3758cfe60332c369.webp)

![Front Desk Mid Section](https://docs.sdlccorp.com/assets/images/05_dashboard_front_desk_mid-9f97639870aeb594fa255d2ba74f9f77.webp)

Key widgets:

- Pending actions list
- Today's arrivals and departures
- Quick check-in / check-out buttons
- Operational alerts (overdue checkouts, no-shows)

<a id="housekeeping-dashboard"></a>

## Housekeeping Dashboard

Housekeeping-focused view for cleaning staff and supervisors.

![Housekeeping Dashboard](https://docs.sdlccorp.com/assets/images/06_dashboard_hk_focused-e73ff88849d9e29a93415082b3654614.webp)

Shows:

- Dirty rooms count
- Tasks completed today
- Staff workload
- Maintenance alerts

<a id="owner-dashboard"></a>

## Owner Dashboard

Financial overview for property owners and managers.

![Owner Stats](https://docs.sdlccorp.com/assets/images/07_dashboard_owner_stats-d669d57f60e2df1b5285cff28be3db58.webp)

Metrics include:

| Metric | Description |
| --- | --- |
| **Today's Revenue** | Revenue recognized today |
| **Booking Rate** | Current booking velocity |
| **ADR** | Average Daily Rate |
| **RevPAR** | Revenue Per Available Room |
| **Yesterday Revenue** | Previous day comparison |
| **Month Revenue** | Current month total |

<a id="analytics-dashboard"></a>

## Analytics Dashboard

Visual analytics with charts and trend analysis.

![Analytics KPIs](https://docs.sdlccorp.com/assets/images/08_dashboard_analytics_kpis-aa5303928dd0164326f07a5f440d8209.webp)

![Analytics Charts](https://docs.sdlccorp.com/assets/images/09_dashboard_analytics_charts-fab04cc59171d9ed7999729d6ad80796.webp)

Includes:

- Occupancy trend charts
- Revenue trend over time
- Booking source distribution
- Room type performance
- Average stay duration
- Guest demographics

<a id="quick-actions"></a>

## Quick Actions

Every dashboard includes quick-access buttons:

- **Room Grid** - Visual room layout with status colors
- **Analytics** - Jump to analytics view
- **Calendar** - Calendar view of reservations
- **Refresh** - Manual data refresh
- **Filters** - Filter by property, date range

<a id="multi-property-switching"></a>

## Multi-Property Switching

If you manage multiple properties, use the **All Properties** dropdown in the dashboard header to switch between them or view consolidated data.
