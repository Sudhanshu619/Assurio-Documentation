# Calendar & Room Grid

Visualize reservations, room availability, and occupancy through interactive calendar and grid views.

<a id="calendar-view"></a>

## Calendar View

Access via **Dashboard > Calendar** or the **Calendar** icon in the dashboard toolbar.

<a id="month-view"></a>

### Month View

![Calendar Month](https://docs.sdlccorp.com/assets/images/11_calendar_month-5443ff0774c0cbf450dc58c5075b4d5c.webp)

Shows all reservations for the current month with:

- Guest name
- Room number
- Check-in and check-out dates
- Status colors (draft, confirmed, checked in, etc.)

<a id="week-view"></a>

### Week View

![Calendar Week](https://docs.sdlccorp.com/assets/images/12_calendar_week-fb115cad58b8f10082e44af0adc19906.webp)

Detailed week view with:

- Day-by-day breakdown
- Hover for reservation details
- Click to open reservation
- Drag & drop to reschedule (if enabled)

<a id="interactions"></a>

### Interactions

- **Click a date** - Create a new reservation for that date
- **Click a reservation** - Open the reservation form
- **Drag a reservation** - Move to different dates
- **Filter** - By property, room type, status

<a id="room-grid-view"></a>

## Room Grid View

The Room Grid provides a visual overview of all rooms and their current status.

![Room Grid Overview](https://docs.sdlccorp.com/assets/images/14_room_grid_overview-783ac8ea8258bc2bc203979dbd0f329d.webp)

<a id="status-colors"></a>

### Status Colors

| Color | Meaning |
| --- | --- |
| **Green** | Available |
| **Blue** | Occupied |
| **Yellow** | Reserved (not yet checked in) |
| **Orange** | Checked out (needs cleaning) |
| **Red** | Out of service / Maintenance |
| **Grey** | Dirty / Housekeeping needed |

<a id="filters"></a>

### Filters

![Room Grid Filters](https://docs.sdlccorp.com/assets/images/15_room_grid_filters-ee08ab75a65d159e067914c1fa9fa07e.webp)

Filter the grid by:

- **Property** (for multi-property operations)
- **Floor** (show only specific floors)
- **Room Type** (Standard, Deluxe, Suite, etc.)
- **Status** (available, occupied, dirty, etc.)
- **Date Range** (see availability for future dates)

<a id="quick-actions"></a>

### Quick Actions

Click any room to see:

- Current guest (if occupied)
- Next reservation
- Housekeeping status
- Recent history
- Quick buttons: **Assign Reservation**, **Mark Clean**, **Report Issue**

tip

Use the Room Grid during daily stand-up meetings. It gives everyone a clear visual of hotel status at a glance.
