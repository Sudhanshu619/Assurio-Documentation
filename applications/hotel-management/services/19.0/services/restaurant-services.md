# Restaurant & Services

Manage the hotel restaurant, in-room dining, laundry, spa, transport, and any custom services - all integrated with guest folios for automatic billing.

<a id="restaurant-management"></a>

## Restaurant Management

Full table management and ordering system accessible via **Operations > Restaurant**.

<a id="tables"></a>

### Tables

Configure restaurant tables:

- Table number and location
- Capacity (number of seats)
- Status (available / occupied / reserved)
- Section (indoor, outdoor, terrace)

<a id="menu-items"></a>

### Menu Items

Create a menu with:

- Item name and description
- Category (appetizer, main course, dessert, beverage)
- Price (by size/portion optional)
- Image
- Availability (breakfast / lunch / dinner only)
- Active / inactive toggle

<a id="kitchen-order-tickets-kot"></a>

### Kitchen Order Tickets (KOT)

When a guest orders food:

1. Staff creates an order linked to the table or room
2. Items are added to the KOT
3. KOT is sent to the kitchen (printed or digital)
4. Kitchen marks items as ready
5. Staff delivers and closes the KOT
6. Charges auto-post to the guest folio (if room-charged) or payment is processed

<a id="room-service"></a>

### Room Service

In-room dining follows the same flow but:

- Order is linked to the guest's reservation
- Charges automatically post to their folio
- No separate payment needed at time of service

<a id="kot-reports"></a>

### KOT Reports

Generate KOT reports via **Reporting > Restaurant** for:

- Daily food revenue
- Item popularity
- Table turnover
- Staff performance

<a id="services"></a>

## Services

Track any additional service the hotel provides.

<a id="service-types"></a>

### Service Types

| Category | Examples |
| --- | --- |
| **Laundry** | Wash, dry clean, ironing |
| **Spa** | Massage, facial, sauna |
| **Transport** | Airport pickup, car rental, tours |
| **Business** | Meeting room rental, printing, business center |
| **Custom** | Flower delivery, personal shopping, babysitting |

<a id="creating-a-service"></a>

### Creating a Service

1. Navigate to **Operations > Services** and click **New**
2. Link to guest and reservation
3. Select service type
4. Set price (or use standard rate)
5. Schedule delivery date/time
6. Assign to staff member
7. Mark as completed when delivered

<a id="auto-billing"></a>

### Auto-Billing

When a service is marked **Completed**, charges automatically post to the guest folio. No manual billing required.

<a id="transport"></a>

## Transport

Manage airport transfers, city tours, and transportation requests.

<a id="fields"></a>

### Fields

| Field | Description |
| --- | --- |
| **Guest** | Linked reservation |
| **Type** | Pickup / Dropoff / Tour / Rental |
| **Pickup Location** | Address or landmark |
| **Destination** | Where they're going |
| **Date / Time** | Scheduled time |
| **Vehicle Type** | Sedan / SUV / Minivan / Luxury |
| **Driver** | Assigned driver |
| **Price** | Service fee |
| **Status** | Scheduled / En Route / Completed / Cancelled |

<a id="integration"></a>

### Integration

- Auto-bill to folio on completion
- Track driver assignments
- Daily transport schedule view
- SMS notifications to guest (if configured)

<a id="feedback-system"></a>

## Feedback System

Collect guest feedback post-stay via **Operations > Feedback**.

<a id="fields-tracked"></a>

### Fields Tracked

- Overall rating (1-5 stars)
- Service quality
- Room quality
- Food quality
- Staff friendliness
- Likelihood to recommend (NPS)
- Open comments

<a id="use-cases"></a>

### Use Cases

- Identify areas for improvement
- Respond to issues promptly
- Showcase positive reviews
- Track staff performance
- Feed into VIP/Repeat Guest reports

tip

Send automatic feedback request emails 1-2 days after checkout. Guests are more likely to respond when the stay is still fresh in their mind.
