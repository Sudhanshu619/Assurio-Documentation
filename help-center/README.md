## Before submitting an issue

Record the exact system/baseline ID, symptom, expected versus actual outcome, time and timezone, affected user role, source system and sanitized diagnostic trace. Do not share access tokens or sensitive raw evidence through unapproved channels.

For a product conversation or demo, use the [official Assurio product page](https://sdlccorp.com/products/assurio/).
